# InfoClass

InfoClass est un site de démonstration pour des cours d’informatique.

## Les pages

- Inscription : formulaire pour choisir un cours.
- Connexion : formulaire avec e-mail et mot de passe.
- Contact : formulaire pour écrire un message.

## Technologies utilisées

- HTML : structure des pages.
- CSS : présentation du site.
- JavaScript : réaction à la soumission des formulaires.

## Ouvrir le site

Télécharger le projet, puis ouvrir index.html dans un navigateur.

## Fonctionnement

Les formulaires vérifient les champs et affichent un message
de démonstration. Ils ne créent pas de comptes et n’envoient
pas de messages.
